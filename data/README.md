# Data Directory

## Overview

This directory contains all data files for the Bridges-NBI-Analysis project.

## Data Files

### Raw Data (Download Required)
- **Finalinfobridgedataset_2024and2025.xlsx**
  - Source: [FHWA National Bridge Inventory](https://www.fhwa.dot.gov/bridge/nbi.cfm)
  - Size: ~82 MB
  - Records: 950,000+
  - Status: **Must be downloaded separately**

### Processed Data (Generated)
- **CleanedBridgeDataset_2024and2025.csv**
  - Generated by: `src/data_cleaning.py`
  - Size: ~115 MB
  - Records: ~950,000 cleaned records
  - Columns: 15 NBI features + derived columns
  - Status: Generated after running preprocessing script
  - *Note: Not stored in Git (see .gitignore)*

## Required NBI Items (15 Columns)

When downloading from FHWA, ensure you select these exact 15 NBI items:

1. Year
2. Item 1 - State Code
3. Item 1 - State Name
4. Item 8 - Structure Number
5. Item 8 (2025) - 2025 NBI Structure Number
6. Item 22 - Owner Agency
7. Item 27 - Year Built
8. Item 43A - Main Span Material
9. Item 43B - Main Span Design
10. Item 48 - Length of Maximum Span (ft.)
11. Item 29 - Average Daily Traffic
12. Item 109 - Average Daily Truck Traffic (Percent ADT)
13. Item 31 - Design Load Descriptor
14. Item 30 - Year of Average Daily Traffic
15. Item 70 - Bridge Posting Code **(Target Variable)**

## Download Instructions

### Step 1: Visit FHWA Website
1. Navigate to: https://www.fhwa.dot.gov/bridge/nbi.cfm
2. Click "Download NBI Data"

### Step 2: Select Years
- Select: **2024 and 2025**
- Both years required for complete dataset

### Step 3: Select Columns
- Use the column selector interface
- Choose all 15 items listed above
- Column names may vary slightly; verify after download

### Step 4: Download
1. Choose Excel (.xlsx) format
2. Download both year files
3. Merge into single file: `Finalinfobridgedataset_2024and2025.xlsx`
   - Or combine in `data_cleaning.py` script

### Step 5: Save Location
```
Bridges-NBI-Analysis/
└── data/
    └── Finalinfobridgedataset_2024and2025.xlsx  ← Place file here
```

## Data Processing

### Cleaning Steps

The `src/data_cleaning.py` script performs:

1. **Loading:** Reads Excel file and validates columns
2. **Validation:** Checks for required NBI items
3. **Missing Values:** Handles nulls via imputation strategy
4. **Data Type Conversion:** Ensures proper types for ML
5. **Outlier Handling:** Filters extreme values in span length/traffic
6. **Encoding:** Converts categorical variables
7. **Output:** Saves cleaned CSV to `data/CleanedBridgeDataset_2024and2025.csv`

### Cleaning Command

```bash
python src/data_cleaning.py
# Input:  data/Finalinfobridgedataset_2024and2025.xlsx
# Output: data/CleanedBridgeDataset_2024and2025.csv
```

## Data Schema (Post-Cleaning)

| Column | Type | Range | Notes |
|--------|------|-------|-------|
| state_code | int | 1-56 | State identifier |
| state_name | string | -- | State name |
| structure_num | string | -- | Unique bridge ID |
| year_built | int | 1800-2025 | Construction year |
| bridge_age | int | 0-225 | Derived: year - year_built |
| span_len | float | 5-3000 ft | Maximum span length |
| truck_pct | float | 0-100 % | Truck traffic percentage |
| is_movable | bool | 0/1 | Movable bridge indicator |
| main_material | int | 0-8 | Material type (encoded) |
| main_design | int | 0-12 | Design type (encoded) |
| owner_agency | int | 0-10 | Owner type (encoded) |
| avg_daily_traffic | float | 0-500K | ADT count |
| posting_code | int | 0/1 | **Target:** 1 = Posted (restricted) |

## Data Statistics

- **Total Records:** 950,000+
- **Missing Values:** ~2-5% per column (handled via imputation)
- **Outliers:** Removed for span_len > 3000 ft
- **Class Distribution:** 
  - Posted (1): ~9.3% (imbalanced)
  - Not Posted (0): ~90.7%
- **State Coverage:** All 50 states + territories

## Feature Engineering

Enhanced dataset includes engineered features:
- **Interaction Terms:** age×truck, span×truck, age×span
- **Polynomial Features:** age², log(span), truck²
- **Categorical Bins:** Material, design, agency categories
- **Total Features:** 26 (7 base + 19 engineered)

See `notebooks/analysis.ipynb` RQ2 section for implementation.

## Data Quality Notes

1. **Year Built:** Some bridges predate modern records; manually verified for data quality
2. **Traffic Data:** Year 2024-2025 ADT used; older data excluded
3. **Posting Code:** Binary classification (posted/not posted)
4. **Missing Values:** Minimal; imputed with column mean for numerical, mode for categorical
5. **Duplicates:** Removed using structure_num as unique identifier
